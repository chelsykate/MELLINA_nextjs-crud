# MELLINA_nextjs-crud

A simple task manager built with Next.js, TypeScript, and SQLite. Tasks can be created, viewed, edited, marked complete, and deleted.

## Run locally

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to use the app. SQLite data is stored locally in `data/tasks.db`.

## Checks

```bash
npm run lint
npm run build
```
